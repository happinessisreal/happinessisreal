<summary><b>About the logos</b> (they're all philosophy jokes)</summary>

- **GridWise.** The best of all possible grids: a bolt strikes the one optimal vertex of the feasible polytope (Leibniz, via Voltaire).
- **Alveelan.** *"এটি অ নয়"*, this is not অ. In code, a symbol is never the thing it names (Magritte).
- **Dhaka AQI.** An ouroboros: the recursive forecast feeds on its own predictions.
- **SCORM Player.** The play button is a Penrose triangle, an impossible object, like full SCORM compliance.
- **Bup Diary.** *The False Mirror*: a diary that looks back. Who is writing whom?
- **Expense Tracker.** Zeno's budget: spend half of what's left, forever.
- **Habit Tracker.** One must imagine Sisyphus happy.

</details>
